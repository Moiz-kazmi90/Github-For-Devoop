# Git Basic Interview Questions

## 1. What is Git?

Git is a distributed version control system used to track changes in source code.

---

## 2. Who created Git?

Git was created by Linus Torvalds in 2005.

---

## 3. Why was Git created?

Git was created to manage Linux Kernel development after BitKeeper's free license was withdrawn.

---

## 4. What is Version Control?

Version Control is a system that tracks changes made to files over time.

---

## 5. What is a Repository?

A repository is a storage location that contains project files and Git history.

---

## 6. Difference between Git and GitHub?

Git is a Version Control System.

GitHub is a cloud platform used to host Git repositories.

---

## 7. What is GitHub?

GitHub is a web-based platform for storing, sharing, and collaborating on Git repositories.

---

## 8. What is a Commit?

A commit is a snapshot of the project at a specific point in time.

---

## 9. What is the Staging Area?

The staging area is a temporary place where changes are prepared before committing.

---

## 10. What is the Working Directory?

The working directory contains the files you are currently editing.

---

## 11. What is HEAD in Git?

HEAD is a pointer to the latest commit in the current branch.

---

## 12. What is the default branch?

The default branch is usually **main**.

---

## 13. Which command initializes a Git repository?

```bash
git init
```

---

## 14. Which command checks repository status?

```bash
git status
```

---

## 15. Which command stages all files?

```bash
git add .
```

---

## 16. Which command creates a commit?

```bash
git commit -m "Commit Message"
```

---

## 17. Which command displays commit history?

```bash
git log
```

---

## 18. Which command pushes code to GitHub?

```bash
git push
```

---

## 19. Which command downloads the latest changes?

```bash
git pull
```

---

## 20. Which command clones a repository?

```bash
git clone repository-url
```

---

# Quick Interview Tips

- Know the difference between Git and GitHub.
- Understand Working Directory, Staging Area, and Repository.
- Practice basic Git commands.
- Explain commits and repositories clearly.
- Learn why Git is used in DevOps and CI/CD.
