# Git Installation

## What is Git?

Git is a distributed version control system used to track changes in source code during software development. It helps developers collaborate, maintain version history, and manage projects efficiently.

---

# Why Use Git?

- Track changes in files
- Collaborate with team members
- Maintain project history
- Restore previous versions
- Create branches for new features
- Merge code safely

---

# Install Git on Windows

1. Download Git from the official website.
2. Run the installer.
3. Keep the default settings.
4. Finish the installation.

Verify installation:

```bash
git --version
```

Example Output:

```text
git version 2.43.0
```

---

# Install Git on Ubuntu/Linux

Update package list:

```bash
sudo apt update
```

Install Git:

```bash
sudo apt install git -y
```

Verify installation:

```bash
git --version
```

---

# Install Git on macOS

Using Homebrew:

```bash
brew install git
```

Check version:

```bash
git --version
```

---

# Check Git Version

```bash
git --version
```

---

# Upgrade Git (Ubuntu)

```bash
sudo apt update
sudo apt upgrade git -y
```
