# History of Git

## Introduction

Git is a distributed version control system used to track changes in source code during software development.

---

# Who Created Git?

Git was created by **Linus Torvalds** in **2005**.

Linus Torvalds is also the creator of the **Linux Kernel**.

---

# Why Was Git Created?

Before Git, the Linux Kernel project used a version control system called **BitKeeper**.

In 2005, the free license for BitKeeper was withdrawn, making it unavailable for Linux kernel development.

Because of this, Linus Torvalds decided to build a new version control system that was:

- Fast
- Distributed
- Secure
- Reliable
- Free and Open Source

The result was **Git**.

---

# Meaning of Git

The word **Git** is British English slang.

Linus Torvalds jokingly said that "Git" can mean:

> "An unpleasant or stupid person."

He chose the name because it was short, unique, and easy to remember.

# Features of Git

- Distributed Version Control
- Fast Performance
- Branching and Merging
- Complete Project History
- Open Source
- Secure Data Storage
- Offline Development
- Team Collaboration

---

# Why Developers Use Git?

- Track code changes
- Work in teams
- Manage different versions
- Recover deleted code
- Maintain project history
- Deploy applications through CI/CD pipelines

---

# Summary

Git was created by Linus Torvalds in 2005 for Linux Kernel development after BitKeeper's free license ended. Today, Git is the industry-standard version control system used by millions of developers worldwide.
